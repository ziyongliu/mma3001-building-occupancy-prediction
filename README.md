## Project Overview

Heating, ventilation, and air-conditioning (HVAC) systems are typically operated on rigid, static time schedules. This wastes significant energy conditioning completely empty lecture theatres, breakout rooms, and offices.

This project develops an automated computational pipeline that processes indoor air quality data (carbon dioxide, temperature, relative humidity, and volatile organic compounds) to estimate whether a room is occupied (`1 = Occupied`, `0 = Vacant`). This provides an edge-deployable signal for dynamic, demand-controlled ventilation.

## Computational Methodology

1. **Telemetry Deserialisation:** The raw environmental data is stored in nested JSON packets (`jsondata`). We parse this semi-structured data into clean columns and remove duplicate packets.
2. **Numerical Method (Temporal Discretisation & Interpolation):** Because environmental sensors log quasi-periodically while occupancy sensors log on motion triggers, their timestamps never match to the exact second. We discretise time into uniform 5-minute intervals and compare **Linear Interpolation vs Cubic Spline Interpolation** to reconstruct missing values during transmission dropouts.
3. **Modelling & Baselines:**
   * **Baseline 1 (Heuristic):** A physical rule threshold based on typical ambient ventilation levels ($CO_2 > 550\text{ ppm}$).
   * **Baseline 2 (Linear):** Standardised Logistic Regression.
   * **Proposed Model (Ensemble):** Random Forest Classifier (depth-limited to prevent overfitting).
4. **Validation Design:** We strictly use a chronological 80/20 train-test split rather than a random shuffle to prevent future data leaking into past predictions.

## Key Results Summary

| Model / Approach | Accuracy | Precision | Recall | F1-Score | Inference Latency |
| :--- | :---: | :---: | :---: | :---: | :---: |
| **Baseline 1 (CO2 > 550ppm)** | 34.4% | 97.6% | 10.7% | 0.192 | 0.002 ms |
| **Baseline 2 (Logistic Regression)** | 73.8% | 75.8% | 94.4% | 0.841 | 0.012 ms |
| **Proposed Model (Random Forest)** | **79.1%** | **80.7%** | **93.9%** | **0.868** | **0.021 ms** |

* **Feature Importance:** Temperature (~39%), Humidity (~26%), and $CO_2$ (~25%) were the strongest indicators of human occupancy.
* **Failure Mode & Thermal Lag:** The model produces occasional false positives when occupants vacate a room. This is due to sensor hysteresis: trapped body heat, moisture, and exhaled $CO_2$ take 15–30 minutes to dilute and ventilate after people leave.
